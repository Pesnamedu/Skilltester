# Skilltester for macOS

## What it does
This project test your skills, including reflex, aim, spam speed, memory, counting in your head, how well you diferentiate or remember colors and how fast you type.

## Other cool features
- Features leaderboard, so you can compete with other users.
- You can see your screen-time.
- You're in full control over the apps appearance.
- Admins can delete/modify other users *Every user can modfy their own account*
- As much account as your computer handles..

# Instalation tutorial
1. Install the .dmg file (found in the latest release)
2. Follow the instructions in the Release tab

## What to do in the app
1. Create your account (the + Icon)
2. **Recomended - toggle the tutorial switch on the login window.**
3. Start any test.
