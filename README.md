# Skilltester for macOS

### What it does
This project test your skills, including reflex, aim, spam speed, memory, counting in your head and how well you diferentiate colors.

### Other cool features
- App also features leaderboard, so you can compete with other users
- You can monitor your screen-time
- You're in full control over the apps appearance.
- Admins can delete/modify other users *Every user can modfy their own account*
- As much account as your computer handles..
